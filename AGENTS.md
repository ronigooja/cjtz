# Project Collaboration Rules

- Execution flow MUST be written in English, including intermediate progress updates, tool/action descriptions, and operational status messages.
- Reports MUST be written in Chinese, including final responses, summaries, findings, review results, and modification proposals that require user confirmation.
- Documentation MUST be in English.
- Before modifying or deleting any file, explain the approach, affected files, and expected impact in Chinese, then wait for the user's confirmation.
